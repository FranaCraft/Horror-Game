# Horror-Game

A short terminal horror game. You’re stuck in a drainage system, the water is rising, and something else is down there with you.

## Play

Use Python 3.10 or newer. Open a terminal in this folder, install the dependencies, then start the game.

On Windows:

```powershell
py -m pip install -r requirements.txt
py main.py
```

On macOS or Linux:

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

At a crossroads, use these keys:

- `j` — left
- `k` — straight (when that path is available)
- `l` — right

Just press the direction key; no Enter needed. The chosen route stays on screen for two seconds, then the next crossroads appears.
